# Architecture Decision Records

Formato: contesto → decisione → alternative considerate → conseguenze. Stati: `Proposta`, `Accettata`, `Sostituita da ADR-XXXX`.
Una ADR non si modifica dopo l'accettazione: se la decisione cambia, se ne scrive una nuova che la sostituisce.
